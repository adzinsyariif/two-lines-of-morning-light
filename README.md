A [make.fun](https://make.fun/bounty/u-gudril-cool-two-lines-of-morning-light-ade94fc5) bounty entry: a program that writes one two-line micro poem about light and morning to `/output/entry.txt`.

## Run

```sh
node main.ts
```

It writes the poem (100 characters, two lines) to `/output/entry.txt` — the same text on every run.

## The poem

> A seam of morning light unzips the curtain's edge;
> the floorboards drink it in, one plank at a time.

One image of light arriving, and the second line opens it: the light moves from the curtain's edge down onto the floor, spreading plank by plank. The room, and the morning, are left unsaid.
